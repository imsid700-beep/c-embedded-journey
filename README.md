# C → Embedded Systems Learning Journey

Long-term, depth-first learning path from C fundamentals to bare-metal
embedded firmware (ARM Cortex-M / STM32), documented as I go.

## Structure
- `01-fundamentals/` — core C basics
- `embedded-c/` — bit manipulation, registers, embedded-specific C
- `bare-metal/` — startup code, linker scripts, no-HAL work
- `drivers/` — peripheral drivers (GPIO, UART, SPI, I2C, ADC, etc.)
- `stm32/` — STM32-specific projects
- `rtos/` — RTOS-based projects
- `projects/` — larger portfolio projects
- `experiments/` — smaller exercises and one-off tests

## Goal
Build genuine, professional-level competence in C and embedded firmware
development — not exam-oriented learning.
